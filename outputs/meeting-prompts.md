# Meeting collection: golden glamour

Balanced directions for performances, dance/DJ, and daytime. Two seeds per concept; curate after viewing at the actual wall dimensions. Uses the existing full Z-Image workflow and shared negative prompt. No generated people, deities, or lettering. Use last year's actual Durga/Sindoor imagery for those program moments.

The P06 prompt was revised after its first sample; the demo uses the second sample. Each catalog record and PNG contains the exact prompt used for that render.
